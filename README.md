# Traceurs Park Landing Page

React + Vite landing page for Trichy Parkour Traceurs Park.

## Run locally

1. Install dependencies:

	npm install

2. Start development server:

	npm run dev

## Build

npm run build

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Run:

	npm run deploy

3. In GitHub repository settings, set Pages source to `gh-pages` branch.

If your repository uses a project subpath and assets fail, update `base` in [vite.config.js](vite.config.js).
